Al instalar y utilizar la app Dinelco Payment Provider, aceptás los siguientes términos.

## 1. Requisitos

- Se requiere una cuenta de comerciante Dinelco válida para usar esta app.
- Debés obtener credenciales de API válidas (Dinelco Secret) de Dinelco o Bepsa.

## 3. Gobernanza de Datos

Esta app transmite datos de sesión de pago (ID de transacción, monto, moneda) a los servidores de Dinelco para iniciar el flujo de pago. No se procesan ni almacenan números de tarjeta ni credenciales de pago sensibles. El tratamiento de datos en el extremo de Dinelco se rige por la política de privacidad y los términos de servicio de Dinelco.
